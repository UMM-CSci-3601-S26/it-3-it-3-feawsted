# ROADMAP

Ready4Supplies has a few issues that are still present within it. Below is a list of some issues or next steps that would be nice to implement.

## Below is a List of Features that can be Improved Upon

### - Purchase-list & Checklist Refreshing

There is an issue with the purchase list and checklist in some edits that do not save when the page is refreshed. Like if you were to assign a priority in the purchase list, then refresh the page, that assigned priority will not get saved and you would have to reassign that item that priority every time you open up that page.

### - Autofill Unfinished

In the branch FilterAuto in VSCode, there is code for a feature that will give a list of filter search options that can be selected from as the user types. Right now, it is only set up for items, but it can be added to more filter options. It also needs more coder coverage on branch outcomes (what happens in an if-else statement).

### - The Home Page Doing Nothing

The home page that is there does nothing for the project as a whole is just there as a placeholder. It would be nice to have the home page to actual do something, like take you to different pages on the website from there.

### - The Website not hand-held friendly

If you open the website link on a phone, the description will fit the screen, but the tables do not, so you have to scroll to see the whole table. It would be nice to have the whole display adjust itself to the size of any given screen just for convenience.

### - Testing in general

We think it would be nice to have more End-to-End testing because we do not think we have had enough. There still might be some errors that do not work as intended, just because we do not have enough End-to-End testing. With the coverage, we mostly just did the bare minimum to be able to have the tests to be able to merge to pass. The project as a whole would benefit with a lot more testing on all the features.

### - Additions to Family

Things that would be nice to have for families are an option to be able to delete families as a whole, and have some kind of warning pop up when you are editing families to make sure you are fine with this.

### - Time Availability Feature

We currently have a Time Availability feature that allows the family to input what times they are available, but there is currently no feature to be able to assign a family a time slot at all. That would be something to add to be able to assign time slots for each student for each family.

### - Adding Inventory

It would have been nice if we were able to take from the requested supplies, have the requested item to create a new inventory for any items not already in inventory, and have its quantity start at zero. When adding an item to the inventory manually, it doesn’t tell you if the item is required or not.
